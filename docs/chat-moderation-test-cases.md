# Chat Moderation Console - Smoke Tests

Дата: 2026-05-11

## Preconditions

- Пользователь с ролью `admin`/`moderator`/`superadmin` авторизован в админке.
- Есть тестовые данные в:
  - `/chats`, `/chats-messages`
  - `/common-chat-messages`
  - `/chat-message-moderation`
  - `/chat-blocked-words`

## 1) Открыть любой чат и просмотреть сообщения

1. Перейти на `/admin/chats`.
2. Нажать `Открыть` у любого чата.
3. Проверить, что открылась страница `/admin/chats/:id`.
4. Убедиться, что таблица сообщений загрузилась.

Ожидаемо:
- Видны поля: `id, text, sender, type, isRead, moderationStatus, isBlocked, createdAt`.
- Работает пагинация.

## 2) Удалить сообщение в личном чате

1. На `/admin/chats/:id` выбрать сообщение.
2. Нажать `Удалить`.
3. Подтвердить в confirm modal.

Ожидаемо:
- Появляется success toast.
- Сообщение исчезает из таблицы после перезагрузки списка.

## 3) Удалить сообщение в общем/категорийном чате

1. Перейти на `/admin/chats/common`.
2. На вкладке `Общий` удалить сообщение через `Удалить` + confirm.
3. Переключиться на вкладку `Категории` и повторить.

Ожидаемо:
- В обоих случаях сообщение удаляется.
- Показывается success toast.

## 4) Заблокировать/разблокировать сообщение через moderation

1. На `/admin/chats/:id` у сообщения нажать `Заблокировать`.
2. Проверить в UI обновление статуса после рефреша списка.
3. Нажать `Разблокировать`.

Ожидаемо:
- Для moderation endpoint отправляется `PATCH /chat-message-moderation/:id`.
- Статус модерации обновляется (`blocked`/`approved`).
- Показывается success toast.

## 5) CRUD стоп-слов

1. Перейти на `/admin/chats/blocked-words`.
2. Создать слово (`Добавить`).
3. Отредактировать слово (`Редактировать`).
4. Деактивировать/активировать.
5. Удалить слово (`Удалить` + confirm).

Ожидаемо:
- Все операции успешны.
- Данные в таблице синхронизируются после каждой операции.

## 6) Проверка ограничений ролей

1. Зайти под ролью вне `admin|moderator|superadmin`.
2. Попробовать открыть любой маршрут `/admin/chats*`.

Ожидаемо:
- Редирект на `/403`.
